ТЕХНИЧЕСКОЕ ЗАДАНИЕ
на разработку корпоративного сайта строительной компании

1. ОБЩАЯ ИНФОРМАЦИЯ

Название проекта: BuildPro — строительная компания
Тип проекта: корпоративный многостраничный сайт
Сложность: средняя
Назначение: презентация строительной компании, её услуг, реализованных объектов и способов связи с потенциальными клиентами.

Сайт должен производить впечатление надёжной, профессиональной и современной строительной компании.

2. ЦЕЛИ САЙТА

Основные задачи:
- представить строительную компанию;
- показать направления деятельности;
- продемонстрировать выполненные проекты;
- сформировать доверие потенциального клиента;
- предоставить информацию о процессе работы;
- дать возможность быстро оставить заявку;
- предоставить контактные данные компании.

Основной путь пользователя:
Главная → Услуги → Проекты → Выбор объекта → Заявка на расчёт.

3. ЦЕЛЕВАЯ АУДИТОРИЯ

Сайт ориентирован на:
- частных клиентов;
- владельцев домов и квартир;
- предпринимателей;
- владельцев коммерческой недвижимости;
- компании, которым требуется строительство или ремонт;
- клиентов, заинтересованных в проектировании и реконструкции.

4. ТЕХНОЛОГИИ

Основная версия:
- HTML5;
- CSS3;
- JavaScript.

Дополнительно разрешается использовать:
- Bootstrap;
- Swiper;
- Google Fonts;
- Font Awesome / Lucide Icons.

Серверная часть на первом этапе не обязательна.

5. СТРУКТУРА САЙТА

Рекомендуемые страницы:
- Главная;
- О компании;
- Услуги;
- Проекты;
- отдельная страница проекта;
- Цены;
- Контакты.

6. ГЛАВНАЯ СТРАНИЦА

6.1. Header

В шапке разместить:
- логотип BuildPro;
- меню: О компании, Услуги, Проекты, Цены, Контакты;
- кнопку «Получить расчёт».

Шапка должна оставаться удобной при прокрутке. На мобильных устройствах реализовать бургер-меню.

6.2. Первый экран

Разместить:
- крупный заголовок;
- краткий рекламный текст;
- кнопку «Рассчитать стоимость»;
- кнопку «Наши проекты»;
- фоновую фотографию современного здания, строительной площадки или готового объекта.

Пример:
«Строим пространства, в которых хочется жить»

Подзаголовок:
«Проектирование, строительство и ремонт объектов под ключ с гарантией качества.»

6.3. Преимущества

Создать 4 карточки:
- 10+ лет опыта;
- 250+ реализованных объектов;
- гарантия до 5 лет;
- соблюдение сроков.

Каждый показатель сопровождается коротким пояснением.

6.4. Услуги

Основные услуги:
1. Строительство домов
2. Ремонт квартир
3. Коммерческое строительство
4. Реконструкция зданий
5. Проектирование
6. Отделочные работы

Каждая услуга должна иметь:
- изображение или иконку;
- название;
- краткое описание;
- кнопку «Подробнее».

6.5. Процесс работы

Показать этапы:
1. Заявка
2. Консультация
3. Расчёт стоимости
4. Проектирование
5. Строительство
6. Сдача объекта

Каждый этап содержит номер и краткое описание.

6.6. Избранные проекты

Отобразить 3–6 лучших объектов.

Карточка проекта:
- фотография;
- название;
- тип объекта;
- площадь;
- год завершения;
- кнопка «Подробнее».

Примеры:
- Частный дом в современном стиле;
- Офисный центр;
- Реконструкция загородного дома;
- Ресторан;
- Жилой комплекс.

6.7. О компании

Разместить:
- фотографию команды или объекта;
- текст о компании;
- основные преимущества;
- кнопку «Подробнее о компании».

6.8. Отзывы

Создать блок отзывов клиентов.

Каждый отзыв содержит:
- имя клиента;
- тип выполненной работы;
- текст отзыва;
- оценку;
- при необходимости фотографию.

Добавить слайдер отзывов.

6.9. Форма расчёта стоимости

Создать заметный CTA-блок:

«Рассчитаем стоимость вашего проекта»

Поля:
- Имя;
- Телефон;
- Тип объекта;
- Примерная площадь;
- Комментарий.

Кнопка:
«Получить расчёт»

После отправки вывести:
«Спасибо! Заявка принята. Мы свяжемся с вами в ближайшее время.»

На первом этапе форма может работать в демонстрационном режиме.

7. СТРАНИЦА «О КОМПАНИИ»

Разместить:
- историю компании;
- миссию;
- ценности;
- команду;
- сертификаты и лицензии;
- фотографии выполненных объектов;
- статистику.

Можно добавить временную шкалу развития компании.

8. СТРАНИЦА «УСЛУГИ»

Для каждой услуги создать отдельный информационный блок или страницу.

Информация:
- название;
- описание;
- преимущества;
- этапы выполнения;
- фотографии;
- ориентировочная стоимость;
- кнопка «Заказать консультацию».

9. СТРАНИЦА «ПРОЕКТЫ»

Создать каталог реализованных проектов.

Фильтры:
- Частные дома;
- Квартиры;
- Коммерческие объекты;
- Реконструкция.

Карточка проекта:
- фотография;
- название;
- категория;
- площадь;
- год;
- краткое описание.

10. СТРАНИЦА ОТДЕЛЬНОГО ПРОЕКТА

Пользователь должен видеть:
- название проекта;
- большую галерею фотографий;
- описание;
- площадь;
- срок строительства;
- тип объекта;
- использованные материалы;
- список выполненных работ;
- дополнительные фотографии;
- кнопку «Хочу такой проект».

Фотографии должны открываться в полноэкранном просмотре.

11. СТРАНИЦА «ЦЕНЫ»

Создать ориентировочные тарифы:

«Старт»
- консультация;
- базовый расчёт;
- предварительная смета.

«Стандарт»
- проектирование;
- расчёт материалов;
- сопровождение;
- строительство.

«Премиум»
- индивидуальный проект;
- полный комплекс работ;
- авторский надзор;
- расширенная гарантия.

Цены могут быть демонстрационными.

Добавить предупреждение:
«Итоговая стоимость рассчитывается индивидуально после оценки проекта.»

12. СТРАНИЦА «КОНТАКТЫ»

Разместить:
- телефон;
- email;
- адрес офиса;
- график работы;
- социальные сети;
- форму обратной связи;
- карту с расположением офиса.

Добавить кнопку «Получить консультацию».

13. ДИЗАЙН

Общий стиль:
- премиальный;
- строгий;
- современный;
- строительный;
- корпоративный.

Рекомендуемая палитра:
- белый / светло-серый;
- графитовый;
- чёрный;
- акцентный жёлтый или оранжевый.

Использовать:
- крупную типографику;
- качественные фотографии архитектуры и объектов;
- геометрические формы;
- небольшие анимации;
- карточки с мягкими тенями.

Сайт не должен выглядеть как простой шаблон конструктора.

14. АДАПТИВНОСТЬ

Сайт должен корректно работать на:
- ПК;
- ноутбуках;
- планшетах;
- смартфонах.

Проверить разрешения:
- 1920px;
- 1440px;
- 1024px;
- 768px;
- 480px;
- 375px.

На мобильных:
- бургер-меню;
- карточки в одну колонку;
- удобная галерея;
- формы на всю ширину;
- удобные кнопки.

15. ИНТЕРАКТИВНОСТЬ

JavaScript должен реализовать:
- мобильное меню;
- плавную навигацию;
- слайдер отзывов;
- галерею проектов;
- фильтрацию проектов;
- модальные окна;
- валидацию форм;
- уведомления после отправки;
- кнопку «Наверх»;
- анимации появления элементов.

16. ФОРМЫ

Форма №1 — «Получить расчёт»:
- Имя;
- телефон;
- тип объекта;
- площадь;
- комментарий.

Форма №2 — «Связаться с нами»:
- Имя;
- телефон или email;
- сообщение.

Проверять:
- обязательные поля;
- корректность email;
- корректность телефона.

18. SEO

Для каждой страницы необходимо задать:
- уникальный title;
- meta description;
- viewport;
- корректную структуру заголовков;
- alt для изображений;
- понятные URL.

Примеры:
«BuildPro — строительство домов под ключ»
«BuildPro — проекты строительной компании»
«BuildPro — услуги строительства и ремонта»

19. ПРОИЗВОДИТЕЛЬНОСТЬ

Необходимо:
- оптимизировать изображения;
- использовать WebP/AVIF;
- не подключать ненужные библиотеки;
- минимизировать тяжёлые анимации;
- использовать lazy loading для изображений;
- обеспечить быструю загрузку страниц.

20. ДОСТУПНОСТЬ

Необходимо:
- обеспечить достаточный контраст;
- использовать читаемые шрифты;
- добавить alt ко всем содержательным изображениям;
- обеспечить навигацию с клавиатуры;
- использовать понятные названия кнопок;
- не передавать информацию только через цвет.

21. БЕЗОПАСНОСТЬ

Необходимо:
- не хранить персональные данные в JavaScript;
- не размещать API-ключи в открытом коде;
- проверять данные форм;
- использовать HTTPS при публикации сайта.

22. ДОПОЛНИТЕЛЬНЫЕ ФУНКЦИИ

По желанию:
- калькулятор примерной стоимости строительства;
- переключатель RU/EN;
- онлайн-консультант;
- интеграция с Telegram;
- отправка заявок на email;
- CRM-интеграция;
- карта объектов;
- раздел «Полезные статьи».

24. ИТОГОВЫЙ РЕЗУЛЬТАТ

В результате должен получиться полноценный современный корпоративный сайт строительной компании BuildPro.

Главный акцент сайта — доверие, качество работ, визуальная демонстрация реализованных проектов и максимально удобное получение заявки от потенциального клиента.
